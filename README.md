# Hi, I'm Furkan Ali

CEIT student at Yıldız Technical University in Istanbul. I love libre software and using it to teach.

## What I do

- Maintain a university computer lab: hardware, multi-user systems, and the local network
- Teach programming. I ran a CS50P-based course for 20+ high school beginners, on a custom GitHub Codespaces setup with check50 and submit50
- Build small Linux and Python tools, mostly for Wayland

## Projects

- [py-sys-manager](https://github.com/FurkannAli/py-sys-manager): Linux system monitor in PySide6 with live graphs, process control, and sensor readings
- [py-way-ocr](https://github.com/FurkannAli/py-way-ocr): select a region of your screen and get the text out, for Wayland
- [py-moji-inserter](https://github.com/FurkannAli/py-moji-inserter): emoji, kaomoji, and symbol picker for Wayland
